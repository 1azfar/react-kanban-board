
A Kanban-style task management application built using React. The application allows users to organize tasks across different workflow stages and manage progress efficiently.

## Features

* Create new tasks
* Delete tasks
* Move tasks between columns
* Responsive user interface
* Component-based architecture

## Technologies Used

* React
* JavaScript
* CSS
* Vite

## Installation

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

## Project Structure

* Components for reusable UI elements
* State management using React hooks
* Organized task workflow system
